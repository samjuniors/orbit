WELCOME TO ORBIT

Your local background coding worker

ORBIT connects authorized issues from your Linear task queue to local coding agents on your Windows PC. It executes work inside isolated Git worktrees, keeping your main branch safe.

🔍
Automatic Discovery

Finds your local Node.js, Git, and verified agent CLIs (Antigravity and OpenCode) with zero manual path hunting.

🛡️
Supervised & Safe

Runs in Supervised mode by default. You approve tasks before the agent runs. Push, merge, and PR creation are disabled by default.

📦
Isolated Worktrees

Every task runs in an isolated temporary Git worktree so your active branches and working files are never disrupted.

🪟
Background Tray Execution

After setup, ORBIT runs quietly in the Windows notification area (system tray) without cluttering your desktop.

STEP 4 OF 5

Safety, autonomy & permissions

ORBIT enforces strict guardrails to keep you in control of what code the agent can run and change.

Execution mode: Supervised (Default)

In Supervised mode, ORBIT claims eligible issues from Linear and prepares an isolated Git worktree, but pauses and asks for your approval before the coding agent touches any code.

Safe Process-Level Interceptor: Git push, git merge, and pull request creation are disabled by default. Deployment and force-push are permanently blocked.

Permissions & autonomy

Deployment and force-push are always blocked and cannot be enabled. Every claimed task runs behind a wrapper that intercepts git push/git merge/gh pr create at the process level according to the toggles above.

Schedule

Auto-starts the worker at the window's start and stops it at the end — but a task already running always finishes first; it never gets cut off mid-task.

Background behavior

Closing this window minimizes ORBIT to the system tray. Use the tray menu to pause, configure, or quit.
